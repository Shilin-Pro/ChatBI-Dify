# 测试环境说明

这个项目所有性能数据都是在特定环境下测的，**不能直接套到其他机器上**。

这份文档说明测试环境和影响因素，避免数字被误读。

---

## 硬件环境

| 项目 | 配置 |
|---|---|
| 设备 | 笔记本（RTX 3050 Laptop GPU，4GB 显存） |
| **供电状态** | **未插电源（电池供电）** |
| 运行模式 | 默认电源策略，非高性能模式 |

### 为什么供电状态重要

笔记本在电池模式下会主动限制 CPU / GPU 功耗：

| 影响 | 具体表现 |
|---|---|
| GPU 功耗上限降低 | 显卡无法跑到满频，推理速度下降 |
| CPU 降频 | 混合推理时（部分层在 CPU）更慢 |
| 整体散热策略保守 | 更容易触发降频保护 |

**所以下表中的耗时是「电池供电 + 默认电源策略」下的数字，比接电源时慢。**

## 软件环境

| 项目 | 版本 / 配置 |
|---|---|
| Dify | 1.19.0（Docker Compose，14 个容器） |
| 向量库 | PostgreSQL + pgvector（HNSW，m=16，ef_construction=64） |
| 本地模型运行时 | Ollama 0.40.15 |
| SQL 生成模型 | DeepSeek-V3（SiliconFlow 云端 API） |
| 本地推理模型 | qwen3.5:4b（Q4_K_M 量化，3.49GB） |
| Embedding | bge-m3（1024 维，本地） |
| Rerank | Qwen3-Reranker-8B（SiliconFlow 云端 API） |
| 数据库 | MySQL 8.0（Windows 宿主机，5 张表） |

### GPU 显存约束

```
显卡可用显存：4GB
qwen3.5:4b 模型：3.49GB
```

**装不下整个模型**，Ollama 只能把约 50% 的层放进 GPU，剩余在 CPU 跑。这是混合推理，速度被 CPU 部分拖累。

| 指标 | 数值 |
|---|---|
| 模型总大小 | 3.49 GB |
| 显存中 | 1.75 GB（约 50%） |
| GPU 利用率 | 50~89% |

**如果显存有 8GB，模型能全部进 GPU，推理速度会明显提升。**

## 实测耗时（含环境标注）

### 节点耗时分布（20 次运行平均）

| 节点 | 模型 | 部署 | 耗时 | 占比 |
|---|---|---|---|---|
| LLM（生成 SQL） | DeepSeek-V3 | 云端 API | 4.4s | 15% |
| SQL Query | MySQL | 本地 | 0.06s | 0.2% |
| **LLM 2（解读）** | qwen3.5:4b | **本地** | **20s** | **80%** |
| Knowledge Retrieval | bge-m3 | 本地 | 1.0s | 4% |

**测试条件**：电池供电，默认电源策略。

### 两轮优化的效果

| 优化项 | 优化前 | 优化后 | 提升 |
|---|---|---|---|
| num_ctx 从 14096 降到 4096 | 65.6s | 19.1s | **3.4x** |
| 修 Code 节点误判（V3） | 36.2s | 13.2s | **2.7x** |

**这两组数字的对比是有意义的**——同一台机器、同样的供电状态，只是改了配置。**相对提升（3.4x / 2.7x）比绝对值更可信。**

## 哪些数字受环境影响，哪些不受

| 指标 | 是否受硬件影响 | 说明 |
|---|---|---|
| **准确率**（70% / 94.4%） | ❌ 不受 | 只跟模型能力和 Prompt 有关 |
| **召回率 / MRR** | ❌ 基本不受 | 检索质量与算力无关 |
| **云端 API 耗时**（4.4s） | ❌ 不受 | 走网络，与本地硬件无关 |
| **本地推理耗时**（20s） | ✅ **受** | 显卡、CPU、供电状态都有影响 |
| **端到端耗时** | ✅ **受** | 主要被本地推理拖累 |

**所以：准确率类的数字可以放心引用，耗时类的数字要说明前提。**

---

## 如果要复现

**同样的硬件 + 电池供电** → 应该复现出相近的耗时。

**接了电源或换更强硬件** → 耗时会明显更短，但准确率不变。

**换更大的模型** → 准确率可能提升，但耗时会增加（除非硬件跟得上）。

---

## 一句话总结

**这个项目的准确率数字是可靠的，性能数字是在「电池供电 + 4GB 显卡」这个受限环境下测的，只适合做相对比较，不适合当作绝对值参考。**
